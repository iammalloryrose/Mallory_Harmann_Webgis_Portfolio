# WebGIS & JavaScript Mapping Portfolio

Selected academic projects demonstrating interactive web mapping, spatial data visualization, and web GIS workflows. These projects were developed as part of graduate GIS coursework and are presented here as a curated technical portfolio.

## Featured projects

| Project | Technologies | What it demonstrates |
|---|---|---|
| [TAMU Campus Building Explorer](projects/03-campus-building-explorer/) | JavaScript, Leaflet, GeoJSON | Interactive building polygons, hover highlighting, feature details, and map navigation |
| [Leaflet Web Mapping](projects/02-leaflet-web-mapping/) | JavaScript, Leaflet, HTML/CSS | Interactive markers, popups, circles, polygons, and map events |
| [WebGIS Dashboards & Visualization](projects/04-webgis-dashboards/) | ArcGIS Online, D3.js, Highcharts | Thematic web maps, operational dashboard example, and data visualization |
| [Bounding Box Utility](projects/05-geospatial-javascript/) | JavaScript, HTML | Geographic bounding-box calculation from coordinate input |
| [ArcGIS Online Mapping](projects/01-arcgis-online-mapping/) | ArcGIS Online, Field Maps/Collector workflow | Hosted web mapping and mobile data-collection workflow |

## Getting started

Most browser-based examples can be opened directly from their project folders. Leaflet examples load Leaflet from the unpkg CDN and therefore require an internet connection. ArcGIS Online projects open in Esri-hosted applications and may require an ArcGIS account or permissions.

## About the work

These are selected coursework projects, not production deployments. The repository focuses on representative work rather than retaining every weekly exercise or classroom artifact.

## Data, attribution, and publication notes

The campus building map uses a building-footprint dataset for Texas A&M University. Confirm the dataset's original source, license, and required attribution before publishing the data file publicly. The ArcGIS Online links are hosted externally and remain subject to their owners' sharing settings.
