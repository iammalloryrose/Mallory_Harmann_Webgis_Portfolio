# ArcGIS Online Mapping & Mobile Data Collection

**Tools:** ArcGIS Online, ArcGIS Map Viewer, mobile field-data collection

This coursework project documents the creation of an ArcGIS Instant App, thematic mapping of county-level adult-obesity data, and a mobile collection workflow that uploaded field observations into a hosted layer.

## Online application

[Open the ArcGIS Instant App](https://tamu.maps.arcgis.com/apps/instant/basic/index.html?appid=e228cf4dc3584bc9a133ea98c850aef6)
