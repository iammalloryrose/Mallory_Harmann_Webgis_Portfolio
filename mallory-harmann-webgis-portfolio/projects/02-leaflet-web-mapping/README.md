# Leaflet Web Mapping Examples

**Tools:** JavaScript, HTML, Leaflet 1.9.4

A curated set of introductory web-mapping examples progressing from a basic interactive map to mobile-friendly mapping, custom markers, and a first custom web map.

## Examples

- `QuickstartHarmann.html` — basic Leaflet map setup
- `MobileExampleHarmann.html` — responsive/mobile-oriented map example
- `MarkersExampleHarmann.html` — custom markers and map interaction
- `HarmannFirstWebMap.html` — first customized web map

Open an HTML file in a browser. The examples load Leaflet assets from the unpkg CDN, so an internet connection is required. Screenshots are in `screenshots/`.
