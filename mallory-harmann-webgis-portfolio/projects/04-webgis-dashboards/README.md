# WebGIS Dashboards & Data Visualization

**Tools:** ArcGIS Online, D3.js, Highcharts, HTML, JavaScript

This collection includes an ArcGIS Online snow-removal operations dashboard example and browser-based temperature visualizations built with D3.js and Highcharts. It demonstrates thematic web mapping, dashboard presentation, and JavaScript charting.

## Files

- `D3Chart.html` and `D3CollegeStationTemp.html` — D3.js chart examples
- `HighChart.html` and `HighchartCollegeStationTemp.html` — Highcharts examples
- `screenshots/` — captured examples of the dashboard and visualizations

The ArcGIS Online dashboard was represented by a screenshot in the supplied coursework archive. The original README linked to an unrelated map; that incorrect link has intentionally not been carried forward. Add the correct dashboard URL after verifying its current sharing settings.

The chart examples use externally hosted JavaScript libraries and may require an internet connection.
